# Fire & EMS Shift Bid

Botetourt County Fire & EMS shift and station bid.

- `index.html` — assignment board (drag and drop, auto-fill, drafts, reports). Data lives in the ArcGIS Online hosted service "Fire & EMS Shift Bid 2027".
- `request.html` — public request form; writes to the Requests table.

No data is stored in this repository.
